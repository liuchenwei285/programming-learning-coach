# 提示分级（hint-levels）

> 原则：**永远不给完整答案**。提示只在学习者主动申请时才给，且必须逐级递进。

## 三级提示

| 级别 | 允许说 | 禁止说 |
| :-- | :-- | :-- |
| **L1** | 只指出本题考察的知识点：`本题考查 [[for循环]] 与 [[整数除法与取余]]` | 任何思路、任何代码 |
| **L2** | 思路方向：分解成哪几步、该用什么结构、边界在哪一类情况 | 具体代码、具体表达式、完整算法 |
| **L3** | 关键步骤伪代码（自然语言 + 缩进），最多覆盖骨架 | 可直接编译/运行的完整代码、标准答案 |

## 使用流程（机械约束）

1. 学习者说"提示"/"卡住了"/"给点方向" → 只给 **L1**，并问"还需要更具体的方向吗？"
2. 学习者再次申请 → 给 **L2**。
3. 学习者第三次申请 → 给 **L3**（伪代码）。
4. 无论申请几次，都**不给标准答案**；标准答案只在批改阶段随练习文档给出。
5. 每次给提示都记录到会话（哪题、第几级、时间），批改时写进文档：
   用了 L2/L3 提示的题目，掌握度升级仍按正常规则，但要在评语里注明"本题使用了 Lx 提示"。

## L3 的写法示例（合规）

```
读取 n
总和 = 0
对 i 从 1 到 n：
    当前项 = 由上一项推出（想清楚递推关系）
    总和 += 当前项
输出总和
```

## L3 的反例（违规，代码会拦截）

```c
#include <stdio.h>
int main(void){ int n; scanf("%d",&n); long long s=0,t=0; for(int i=1;i<=n;i++){t=t*10+i;s+=t;} printf("%lld\n",s); }
```

`questions.py` 的校验规则：`hints` 只能是 `{L1,L2,L3}` 的子集；L3 若同时满足
"包含 `#include` / `def xxx(` / `int main` / 以 `;` 结尾的行"且长度 > 400 字符，判定为
"疑似完整答案"，出题直接报错。
